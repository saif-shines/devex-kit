# Dev GTM Plugin

Developer go-to-market strategy skills — authentic storytelling, technical advisory boards, DX for first success, and content taxonomy for dev-facing products.

## Installation

```sh
/plugin marketplace add saif-shines/devex-kit
/plugin install dev-gtm@devex-kit
```

## Skills

| Skill | Slash command | What it does |
|-------|--------------|--------------|
| devrel-story-craft | `/devrel-story-craft` | Design authentic stories, recruit and run TABs, build dev influencer presence, define dev-friendly packaging |
| devrel-dx-craft | `/devrel-dx-craft` | Design DX for first success, choose content types (Sample App vs Recipe vs Pattern), apply content-has-a-job principles |

## Usage

```
/devrel-story-craft review mode. Here's my draft launch story for the new connectors...
```

```
/devrel-story-craft plan TAB for connectors. Help me recruit and draft the first call questions.
```

```
/devrel-dx-craft plan first-success. For the connectors feature, choose Sample Application vs Recipe vs Pattern.
```
